# Portafolio Web — Jhaimar Santiago Velez Palacios

## Descripción

Este proyecto corresponde a un portafolio profesional desarrollado como parte del proceso académico de formación en desarrollo de software.

El sitio presenta información profesional, habilidades técnicas, proyectos realizados y un formulario de contacto simulado mediante JavaScript.

El diseño está orientado a ofrecer una experiencia moderna, organizada y adaptable a diferentes dispositivos.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Visual Studio Code
* Git y GitHub
* GitHub Pages

## Características principales

* Estructura HTML5 semántica.
* Diseño responsive para móviles, tablets y computadores.
* Navegación responsive con menú hamburguesa.
* Sección de presentación profesional.
* Sección de habilidades.
* Lista dinámica de proyectos mediante JavaScript.
* Formulario de contacto con validación HTML5 y JavaScript.
* Animaciones y transiciones CSS.
* Organización modular de archivos CSS y JavaScript.

## Ejecución local

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html`.
4. Ejecutarlo mediante un servidor local, por ejemplo, usando la extensión Live Server de Visual Studio Code.
